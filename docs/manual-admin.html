🗺️ Manual Book Admin

Selamat datang di Pusat Panduan Administrator Website Wisata Gunung Sanggabuana. Dokumen ini dirancang khusus dengan langkah ringkas, modern, dan mudah dipahami agar Anda dapat menguasai pengelolaan website dengan cepat.

Pengenalan Portal

Portal Administrator Wisata Gunung Sanggabuana adalah panel kontrol untuk memperbarui informasi seputar pariwisata alam. Mulai dari memperbarui rincian keunikan jalur pendakian, mengunggah foto galeri keindahan alam, menyeleksi ulasan, hingga merilis status siaga cuaca darurat demi keselamatan pengunjung.

Mudah Digunakan
Formulir isian didesain ramah pengguna dan dilengkapi pengolah teks visual modern.
Aman & Andal
Dilengkapi proteksi sesi administrator untuk memastikan keamanan data portal.
Instan & Responsif
Setiap perubahan konten yang Anda lakukan akan langsung tersaji real-time kepada pengunjung.

🔐 Akses & Autentikasi

Sebelum mengelola website, Anda wajib melakukan otentikasi login melalui formulir khusus yang aman.

🌐 URL Login Admin

Buka peramban (browser) Anda, lalu navigasikan ke halaman berikut:

URL LINK
http://nama-domain-website.com/admin/login

🔑 Kredensial Masuk Utama

Gunakan data akses default berikut untuk masuk ke dashboard admin:

ADMIN DEFAULT CREDENTIALS
Email : admin@sanggabuana.com Password : admin123
Pemberitahuan Keamanan: Harap jaga kerahasiaan data email dan password di atas. Lakukan perubahan kredensial secara berkala jika pengelola sistem sudah memasang modul ganti sandi demi keamanan.

📸 Pengelolaan Galeri Foto

Galeri berguna mengarsipkan rekaman keindahan panorama alam Sanggabuana dalam format visual grid yang rapi.

➕ Langkah Membuat Galeri Foto Baru

  • Navigasikan ke menu Galeri di sidebar kiri, lalu klik tombol Tambah Galeri.
  • Destinasi Terkait: Hubungkan foto dengan salah satu objek wisata pendukung. Jika merupakan foto umum pegunungan, Anda dapat mengosongkannya.
  • Judul & Caption Foto: Berikan judul yang informatif serta caption singkat agar memperkuat aspek visual foto di halaman pengunjung.
  • Berkas Foto: Pilih foto terbaik Anda. Sistem membatasi kapasitas berkas maksimal 5 MB untuk memastikan loading website tetap super cepat.
  • Atur prioritas nomor urutan tampil serta centang status Aktif sebelum menekan tombol Simpan.

💬 Pengelolaan Testimoni & Ulasan

Komentar dan ulasan dari petualang sangat berharga dalam meningkatkan citra kawasan wisata Sanggabuana.

Persetujuan Cepat (Instant Toggle): Anda tidak perlu membuka form edit untuk mempublikasikan ulasan. Cukup klik tombol toggle berstatus Aktif atau Draft pada tabel utama, maka status ulasan di beranda depan langsung berganti detik itu juga!

📝 Parameter Ulasan

Admin juga dapat menerbitkan ulasan manual (misalnya hasil wawancara pengunjung atau ulasan tokoh nasional):

  • Nama Tokoh / Pengunjung: Nama lengkap pemberi testimoni.
  • Peran (Role): Profesi atau gelar, contoh: *Pendaki Profesional*, *Travel Blogger*, *Keluarga Wisatawan*.
  • Penilaian Rating: Skala nilai bintang 1 sampai 5 bintang.
  • Foto Profil / Avatar: Wajah pemberi ulasan (Maksimal berkas 2 MB).

📄 Pengelolaan Halaman Informasi

Halaman Informasi digunakan untuk menulis dokumen hukum atau profil umum seperti halaman *Tentang Kami*, *Syarat & Ketentuan*, dan *Panduan Pendakian Aman*.

🛠️ Keunggulan Fitur Halaman

  • Visual Editor (WYSIWYG): Anda bebas berkreasi merancang struktur tulisan menggunakan tebal, miring, list balet, hingga menyisipkan link artikel eksternal.
  • Otomatisasi Slug: Tulis judul halaman Anda, sistem akan merapikan link URL halaman tersebut secara otomatis agar ramah mesin pencarian Google (misal judul "Syarat & Ketentuan" berubah menjadi link akhir "halaman/syarat-ketentuan").
  • SEO Meta Deskripsi: Sediakan rangkuman halaman 1-2 kalimat agar situs Anda mendapat posisi strategis pada pencarian Google.

✉️ Manajemen Pesan Masuk (Kontak)

Saluran komunikasi utama pengunjung ke meja kerja admin untuk pertanyaan, kritik, atau kerja sama bisnis.

📥 Prosedur Pengelolaan Pesan

  • Indikator Notifikasi: Ikon pesan pada dashboard menyala dengan tanda merah jika terdapat pesan baru.
  • Baca Detil Pesan: Klik baris pesan pada tabel kontak. Sistem otomatis menampilkan isi pesan lengkap dan langsung mengubah status pesan menjadi Sudah Dibaca secara cerdas.
  • Penghapusan Berkas: Untuk menjaga kerapihan penyimpanan database, Anda dapat membuang pesan bernada spam dengan menekan ikon tong sampah merah pada daftar aksi.

☁️ Kondisi Jalur & Siaga Cuaca

Fitur krusial bagi pariwisata alam pegunungan untuk menjaga keselamatan petualang dari bahaya cuaca buruk di wilayah Sanggabuana.

Status Darurat: Gunakan Mode Manual jika terjadi badai, longsor, pohon tumbang, atau penutupan berkala jalur pendakian agar pengunjung mendapat peringatan yang mencolok di beranda depan.

🔄 Pilihan Mode Siaga Cuaca

MODE OTOMATIS (AUTO)

Sistem memonitor cuaca dari server BMKG/Weather API berdasarkan koordinat Latitude & Longitude yang diinput. Sangat praktis untuk kondisi normal sehari-hari.

MODE MANUAL (DARURAT)

Admin mengabaikan pembacaan otomatis dan memasang status siaga buatan secara mandiri. Sangat efektif memblokir akses sementara karena force majeure.

✍️ Formulir Siaga Manual

  • Status Manual / Darurat: Judul pesan peringatan singkat, misal: Jalur Pendakian Ditutup sementara
  • Deskripsi Kondisi: Detail info penyebab penutupan, misal: Penutupan jalur dari Pos 2 akibat hujan badai ekstrem dan risiko pohon tumbang
  • Ikon Status: Pilih ikon penunjang visual darurat, seperti ikon segitiga peringatan (alert-triangle).

👥 Role-Based Access Control (RBAC) & Manajemen Kasir

Sistem pariwisata Gunung Sanggabuana kini dilengkapi dengan fitur keamanan Role-Based Access Control (RBAC) yang membagi wewenang admin ke dalam 3 tingkatan peran (role) yang berbeda demi menjaga integritas data masing-masing destinasi wisata.

🎭 Tingkatan Peran & Wewenang

Peran (Role) Hak Akses Utama Batasan Akses
Superadmin Seluruh fitur sistem + Kelola Pengguna & Peran (RBAC) Tidak ada batasan akses.
Admin Mengelola seluruh Konten Wisata, Interaksi, Halaman, dan Pengaturan Tidak dapat mengelola user/peran baru (Menu Kelola Pengguna disembunyikan).
Kasir Mengakses loket POS (Point of Sales) tiket destinasi tugasnya & mengedit destinasi tugasnya saja Hanya dapat mengakses Dashboard Kasir dan mengedit destinasi tugasnya. Tidak dapat mengakses Galeri, Halaman, Pesan, Pengaturan, atau membuat/menghapus destinasi.

🔑 Kredensial Default Peran Baru

Sistem secara otomatis menyediakan kredensial bawaan berikut di database untuk kemudahan uji coba:

  • Super Administrator: Email superadmin@sanggabuana.com / Password superadmin123 (Role: Superadmin)
  • Administrator: Email admin@sanggabuana.com / Password admin123 (Role: Admin)
  • Kasir Destinasi: Email kasir.[slug]@sanggabuana.com (contoh: kasir.gunung-sanggabuana@sanggabuana.com) / Password kasir123 (Role: Kasir)

🖥️ Fitur Khusus Kasir & POS Simulator

Saat login sebagai kasir, antarmuka akan disesuaikan secara dinamis:

  • Dasbor Loket POS: Modul kasir terintegrasi untuk memasukkan jumlah tiket dan metode pembayaran, dilengkapi dengan kalkulator harga instan.
  • Cetak Receipt & QR Code: Visualisasi struk transaksi dan scan check-in QR Code secara visual interaktif.
  • Log Transaksi Penjualan: Rekapitulasi daftar transaksi harian untuk memudahkan pelaporan.
  • Destinasi Saya: Menu akses cepat untuk memperbarui rincian operasional dan status cuaca destinasi wisata di bawah tanggung jawab kasir secara aman.
